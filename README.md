# CleaningCapstone

**Team:Logan Sansoucie**

## Project Abstract
i work for a cleaning company and right now everything is tracked pretty informally, so for my project i wanted to build something that actually organizes it. this is a scheduling and documentation app for the cleaning company i work for. it lets an admin add "houses" (clients) with their name, nickname, address, cleaning preferences, and notes about the property. it also handles scheduling cleaning jobs, including recurring ones like weekly or biweekly cleans. cleaners can leave notes after a visit that get tied to that house's history. there's also a client view where a client can check when they're paid up to and see any notes left for them, using a unique link instead of a full login. i think it'll actually be useful for the company i work for, not just something that gets thrown away after the semester.
